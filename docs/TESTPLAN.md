# COBOL Account Management Test Plan

## Scope

This plan covers the behavior currently implemented by `MainProgram`, `Operations`, and `DataProgram`. It is intended for business stakeholder review and as a basis for unit and integration tests during the Node.js migration. Unless stated otherwise, begin each test in a fresh application process; the current in-memory balance starts at `1000.00` and is not persisted after the process ends.

All cases are unexecuted. Record observed results and set each status to Pass or Fail during validation. Cases marked for stakeholder decision describe behavior that the COBOL source does not define clearly; agree on the intended rule before using it as a Node.js acceptance criterion.
